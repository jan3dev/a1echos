# Vendored dictionary data attribution

`en_US_wordlist.combined.gz` is vendored unmodified from the Android Open
Source Project, `platform/packages/inputmethods/LatinIME`
(`dictionaries/en_US_wordlist.combined.gz`, dictionary version 54, dated
2014-10-31), licensed under the Apache License, Version 2.0.

The build (`scripts/keyboard-dictionary/build.js`) reads only the lowercase
alphabetic entries and maps their `f` byte onto the SymSpell log-frequency
scale; the archive itself is not shipped.
